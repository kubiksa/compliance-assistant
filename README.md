# compliance-assistant

Open-source tools for making regulatory compliance understandable to people who are
not compliance specialists.

## Tools

**[compliance-catalog](compliance-catalog/)** generates a single, self-contained HTML
file that explains which regulations apply, what each requires in plain language, and
which documents address each requirement. It runs offline in any browser, with no
server or login. See the example built from `compliance-catalog/data-example/`.
