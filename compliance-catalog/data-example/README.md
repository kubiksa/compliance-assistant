# Example dataset

A complete catalog for Northfield Systems, Inc., a fictional US public company with EU
customers that is working toward SOC 2 and ISO 27001. It covers SOC 2, ISO/IEC 27001:2022,
the NIST Cybersecurity Framework 2.0, GDPR, and the SEC cybersecurity disclosure rule.

Statuses, documents, and dates for Northfield are invented to show every feature:
partial and missing coverage with rationales, overdue reviews, restricted documents, a
document not yet filed, and upcoming internal milestones.

GDPR and NIST CSF text marked as official wording is quoted from the public sources.
SOC 2, ISO 27001, and SEC entries are summaries and are labeled as such in the catalog.

Build it with `npm run build:example`.
